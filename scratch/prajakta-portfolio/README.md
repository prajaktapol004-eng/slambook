### 🌐 Free 1-Click Hosting Guide

#### Option A: GitHub Pages
1. Create a repository on GitHub (e.g., `prajakta-portfolio`).
2. Upload `index.html`, `prajakta-photo.jpg`, `favicon.svg`, and `resume.pdf`.
3. Go to **Settings > Pages** > Set branch to `main` and root to `/` > Save.
4. Your website will be live at `https://<username>.github.io/prajakta-portfolio/`.

#### Option B: Netlify or Vercel
- Simply drag and drop the `prajakta-portfolio` folder into the Netlify Drop dashboard for instant deployment with an SSL certificate.
